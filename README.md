# 🔐 Malicious URLs Detection Using Machine Learning

This project aims to detect **malicious URLs** using a Machine Learning model and integrates it into a **browser extension** for real-time protection while browsing the internet.

---

## 🚀 Features

- Detects phishing, malware, and suspicious URLs
- Machine learning model trained on real-world URL datasets
- Lightweight and fast URL prediction
- Browser extension integration for real-time protection
- Simple and intuitive user interface

---

## 🧠 Technologies Used

- **Python** (for model training)
- **scikit-learn**, **pandas**, **NumPy**
- **Flask / FastAPI** (to serve model as API)
- **JavaScript, HTML, CSS** (browser extension)
- **Google Chrome Extension APIs**
